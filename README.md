# NO Cable – דאשבורד שירות לקוחות

פרויקט לימודי: דאשבורד לצוות שירות הלקוחות של חברת כבלים (נתוני דוגמה).

- איפיון מלא: [SPEC.md](./SPEC.md)
- כללי עבודה: [Practice.md](./Practice.md)

## הרצה

פותחים את `index.html` בדפדפן. אין התקנה ואין build.

## טכנולוגיה

HTML + CSS + JavaScript רגיל, ללא ספריות. הנימוקים: SPEC.md סעיף 2.

## מקור הנתונים

הנתונים נקראים מטבלה ב-Airtable. הטוקן (לקריאה בלבד, ורק על בסיס זה) נמצא ב-`config.js` ויבוטל בתום הבדיקה. בלי טוקן, או אם החיבור נכשל, מוצגים נתוני דוגמה. הפרטים ב-SPEC.md סעיף 2.2.

## פריסה

GitHub Pages, ישירות מהענף (Settings → Pages → Deploy from a branch).

## מסך מחקר שוק (Apify)

הטאב "מחקר שוק" משווה את No Cable למתחרים (HOT, yes, Partner TV, Cellcom TV) ולשירות סטרימינג (Netflix): סנטימנט לפי חברה, מגמה שבועית והתגובות עם הכי הרבה מעורבות. האיפיון: SPEC.md סעיף 14.

- הנתונים הם תגובות לקוחות בדפי הפייסבוק הציבוריים של החברות, שנאספות עם [Apify](https://www.apify.com).
- **כרגע מוצגת דגימה** בפורמט הפלט של Apify (`market-data.js`), לא נתונים חיים. No Cable היא חברה בדיונית ולכן הנתונים שלה תמיד דגימה.
- לרענון נתוני המתחרים: `APIFY_TOKEN=<הטוקן שלכם> node scripts/fetch-apify.mjs` (Node 18+, בלי התקנה; אפשר לציין שם חברה). הטוקן רץ מקומית בלבד ואינו נכנס לקוד האתר.
